# 01-接入域 · 域分册（采集工厂）

> 上游域：—（外部：真机/机器人本体/仿真器/动捕设备） ｜ 下游域：[02-生产域](../02-生产域/README.md) ｜ 输入制品：外部原始信号 ｜ 输出制品：**RawDataPackage**（原始文件 + schema 元数据）

## 1. 域职责

多源数据接入（真机遥操作、第一视角、仿真、动捕、rosbag）、设备/机器人管理、数据上云、源头完整性校验、**仿真源适配（GT 旁路接入）**。边界：不管算子执行（生产域）、不管调度（管控域）。

## 2. 关键组件

采集 Agent/客户端、设备管理服务、数据接入网关、仿真源适配器、原始数据湖（对象存储）。

## 3. 域间契约

接入 → 生产：`RawDataPackage`；准入校验 = 源头完整性、schema、合规标记——**不达标不跨域**（[总线 §4.2](../00-总体架构/README.md)）。

## 5. 关键机制与质量门

源头校验三查（完整性/schema/合规）是全平台第一道闸——拦截在源头最省 GPU 成本；仿真源自带 GT 走旁路接入（三套 GT 分工见[总线 §5.3](../00-总体架构/README.md)）。
