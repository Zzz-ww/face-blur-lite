# 03-管控域 · 域分册（控制面）

> 上游域：用户入口（声明式 PipelineSpec） ｜ 下游域：[02-生产域](../02-生产域/README.md)（驱动数据面执行） ｜ 输入制品：PipelineSpec ｜ 输出制品：作业生命周期状态

## 1. 域职责

任务编排（DAG/重试/断点续跑）、调度（队列/配额/优先级/gang scheduling）、状态机与生命周期、资源管理、多租户分池。控制面与数据面严格分离——只通过声明式规格交互（[总线 §1.2](../00-总体架构/README.md)）。

## 2. 关键组件

KubeRay（RayCluster/RayJob/RayService 三 CRD）、Kueue 调度器（ElasticQuotaTree）、状态存储（etcd/元数据库）、任务管理服务。

## 3. 域间契约

声明式 PipelineSpec → 作业生命周期状态；作业吃数据集、产数据集（数据集为中心原则），跨域只传标准制品。

## 5. 关键机制与质量门

本域是 **L2 管线工程指标**（通吃率/人工介入率/端到端成功率）与 **L3 性能成本指标**（GPU 秒/样本/吞吐/队列延迟）的落点域之一；断点续跑 = at-least-once + 检查点 + 幂等重跑。
