# 04-治理域 · 域分册

> 上游域：[02-生产域](../02-生产域/README.md) ｜ 下游域：[05-资产域](../05-资产域/README.md)（晋升）；[01-接入域](../01-接入域/README.md)/[02-生产域](../02-生产域/README.md)（回流指令） ｜ 输入制品：StructuredDataset + AnnotationSet + QCReport ｜ 输出制品：**DatasetVersion**（晋升令牌）+ 回流任务/补采指令

## 1. 域职责

数据集版本管理（不可变快照）、血缘追踪（制品化）、质量门禁（规则→互检→抽检→Golden Set 回归→发布审批）、合规引擎、四层评测（L1–L4）与回归。

## 2. 关键组件

元数据/血缘服务、版本服务、质检网关、评测回归服务、合规引擎。

## 3. 域间契约

- 生产 → 治理：阶段门 G0–G4 准入
- 治理 → 资产：`DatasetVersion` 晋升令牌（全门禁 G5/G6 + 发布审批）
- 消费 → 治理：`EvaluationReport + Badcase`（回流标记 + 血缘定位）
- 治理 → 生产/接入：回流任务/补采指令（缺陷分类 + 目标算子）

（契约总表见[总线 §4.2](../00-总体架构/README.md)）
