# 02-生产域 · 域分册（数据面 · 算子流水线）

> 上游域：[01-接入域](../01-接入域/README.md) ｜ 下游域：[04-治理域](../04-治理域/README.md) ｜ 输入制品：RawDataPackage + PipelineSpec ｜ 输出制品：**StructuredDataset + AnnotationSet + QCReport**

## 1. 域职责

执行算子全集：预处理（帧规范化）、感知结构化（检测/重建/深度/位姿）、语义标注（VLM）、标注（自动标注 + 人工标注台 + 标注质检）、清洗质检、脱敏合规、格式封装（LeRobot v2/v3 / RLDS）。边界：不管调度与资源（管控域）、不管版本晋升（治理域）。

## 2. 关键组件

算子库（Data-Juicer 式）、算子引擎（CPU Ray Data / GPU Actor 池 / RayJob / RayService）、算子 DAG 执行器、标注服务（自动 + 人工）。

## 3. 域间契约

生产 → 治理：`StructuredDataset + AnnotationSet + QCReport`；准入校验 = 阶段门 **G0–G4**（[总线 §4.2](../00-总体架构/README.md)）。
