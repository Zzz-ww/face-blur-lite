# 标注体系 02：标注质检与来源标记

> 02-生产域 标注体系第 2 篇（**示例篇**）。回答两个问题：① 每条标注「从哪来、可信吗」——**来源标记**；② 怎么系统性地验证标注——**质检手段 + 指标 + 门禁**。上位制品 = [总线 §4.1 AnnotationSet](../../00-总体架构/README.md) 与 §5.3 三套 GT；质检算子与门禁口径 = [算子设计-02 §5/§9](../算子设计/算子设计-02-算子接口规范与质量门体系.md)；姊妹篇 [01-自动标注与人工标注台](01-自动标注与人工标注台.md) 讲「标注怎么产出」，本篇讲「产出后怎么验、怎么溯源」。

## 1. 定位与边界

- **本篇管**：标注的**来源标记、质检手段、质量指标、门禁衔接、溯源血缘**——是"裁判"，不亲自产生标注
- **姊妹篇 01 管**：自动标注与人工标注台如何分工协作产出标注（生产流程、标注台、人工任务类型）
- **制品归属**：所有标注汇入 `AnnotationSet`，本篇定义其 `label_source / confidence / annotator / qc_status` 字段如何被正确填写与校验
- **红线立场**：来源不可追溯的标注 = 不可用标注；来源标记错误比标注本身错误更危险（污染评测与回归）

## 2. 核心概念：来源标记 label_source（四分类）

每条标注必须带且仅带一个主来源标记，对齐总线 §4.1：

| label_source | 含义 | 典型产出方 | 默认可信度 | 能否进训练 |
| --- | --- | --- | --- | --- |
| `sim_GT` | 仿真器导出的全真值 | 仿真 GT 旁路（深度/位姿/分割/动作） | 高（真值，受仿真保真度限） | 能（预训练主力） |
| `pseudo_GT` | 强模型对真实数据打的伪标签 | MegaSaM/HaWoR/MoGe 等强模型 | 中（须带置信度，可被真实 GT 推翻） | 能（需配比/加权） |
| `human_GT` | 人工标注/精标 | 标注台标注员 | 最高（受标注员一致性约束） | 能（精标/微调） |
| `model` | 生产模型的常规自动输出 | VLM 指令、自动分割/检测等 | 中低（默认全量、待抽检） | 能（过检后） |

> 区分要点：`pseudo_GT` 与 `model` 同为模型产出，差别在**用途定位**——pseudo_GT 是被当作"近似真值"去训练/评测其他模型的强模型标签；model 是产线常规自动标注。两者都**不得**在最终结论中冒充 `human_GT`。

## 3. 三套 GT 评测体系（用途不可混用）

沿用总线 §5.3，是来源标记在评测侧的落地：

| 评测手段 | 来源标记 | 规模/成本 | 职责 | 能不能进训练 |
| --- | --- | --- | --- | --- |
| **仿真合成 GT（主力）** | sim_GT | 大规模、低成本、全真值 | 算法迭代主评测（L1 算法指标） | 能（预训练） |
| **伪 GT（补真实域）** | pseudo_GT | 中等、自动 | 补真实域缺口，扩大训练标注 | 能（加权/配比） |
| **真实 Hold-out GT（最终验证）** | human_GT | 小规模、贵、人工精标 | 最终结论，**冻结不参与训练** | **不能（只评测）** |

- **配比方向参照**：CloudRobo 真实/生成约 20% 真机 / 80% 生成（见[算子设计-05 核实状态](../算子设计/算子设计-05-采集源差异矩阵.md)，仅作方向，非本团队定标）
- **Sim2Real 域错配**：合成预训练 + 少量真实微调，域间指标差距过大触发约束正则或真实补采（GeoPT 范式：借范式、不借身份）

## 4. 质检手段（四级漏斗，逐级兜底）

```
全量自动 → 规则校验 → 模型自检/互检 → 分层抽检(人工) → 人工精标(Golden/Hold-out)
 便宜、全量                                    贵、小样本、最终标尺
```

1. **规则校验（全量·自动）**：schema、字段范围、时间戳对齐、几何一致性（如手-物穿模、位姿跳变）——便宜，先拦硬错误
2. **模型自检 + 双模型互检（全量·自动）**：
   - 自检：每模型自带 `confidence`，低于阈值（示例：手部置信度 <0.6）进人工队列
   - 互检 `op-clean-crosseval`：两个**独立失败模式**的模型对同一输入出结果，一致则过、分歧则仲裁（MoGe↔DAv2、Hamer+HaWoR 示例）
3. **分层抽检（抽样·人工）** `op-clean-sample`：按来源 / 置信度 / 类别 / 采集源分层，**高风险层高抽样率**；输出复核一致率
4. **人工精标（小样本·最高标尺）**：Golden Set 与真实 Hold-out 集由专家多轮精标，作为回归与最终评测的基准

**路由规则**：低置信度 / 互检分歧 / 规则异常 → 人工介入队列（标注台承接，见 01）；人工修正结果回流并触发模型/规则迭代。

## 5. 指标与质量门

| 指标 | 定义 | 默认阈值 | 对应门禁 | 失败处理 |
| --- | --- | --- | --- | --- |
| 分层抽检一致率 | 自动标注与人工复核的一致比例 | ≥95% | G2 结构化门 | 不达标回流模型/提高抽检 |
| 指令可用率 | VLM 指令抽检可执行、与片段一致比例 | ≥90% | G3 语义门 | 人工修正/VLM 重跑 |
| 通吃率 | 批次无需人工介入自动通过的比例 | ≥90% | G2（单算子）/ G4（整批） | 低于阈值排查模型/数据 |
| 人工介入率 | 需人工介入样本占比 | ≤10% | G4 工程门 | 反推自动模型/规则短板 |
| 违规率 | 合规/隐私违规样本占比 | **=0（硬红线）** | G4 工程门 | 全批拦截 |
| 标注员一致性 | 标注员间 IAA / Cohen's Kappa | 团队自定（建议 Kappa≥0.8） | 人工质检内部门 | 不一致则培训/修订规范 |
| 双模型分歧率 | 互检两模型输出不一致比例 | 监控无硬阈值 | 观察 + 仲裁 | 分歧件进人工仲裁 |

> 通吃率与人工介入率是一枚硬币两面，合计趋势应接近 100%；二者同时劣化通常意味着输入域漂移或模型退化。

## 6. 数据结构：AnnotationSet 质检字段

```yaml
annotation:
  ann_id: <全局唯一>
  target: {object_type: hand|object|scene|action, ref_id: <轨迹/帧/片段 id>}
  label_source: sim_GT | pseudo_GT | human_GT | model   # 必填，仅一个主来源
  confidence: <0..1>            # 模型/伪 GT 必填；human_GT 可填标注员把握度
  annotator:                    # 来源为模型→模型版本；人工→标注员 id
    kind: model | human
    ref: hawor_cvpr25 | annotator_007
  qc_status: pending | pass | flagged | rejected | human_fixed
  qc_trace:                     # 质检留痕（血缘）
    - {check: rule, result: pass}
    - {check: crosseval, result: disagree, arbiter: human}
    - {check: stratified_sample, reviewer: annotator_003, result: human_fixed}
  model_version: <模型三锁之一>
  operator_version: <算子三锁之一>
  data_version: <数据三锁之一>
```

- 每条标注可经三锁 + annotator 完整溯源到"哪版数据、哪版算子/模型、哪个人"
- 人工修正不复用原 id 的 qc 记录，保留 `human_fixed` 轨迹（不抹掉历史）

## 8. 红线与速讲话术

**红线**：
1. **label_source 不得混标**：model / pseudo_GT 严禁冒充 human_GT；一旦混标，评测与回归结论全部失真
2. **三套 GT 用途不可混用**：真实 Hold-out 集冻结、绝不进训练；伪 GT 不能作为最终结论
3. **违规率=0 是硬红线**：合规/隐私问题全批拦截，不允许"带瑕流转"
4. **互检的两个模型必须是独立失败模式**（不同方法族）；同源模型互检 = 相关错误，无质检意义
5. **人工复核天然不可复现**：含人工的环节标"自动部分幂等"，不得对人工结果声明逐位一致

**速讲话术（30 秒）**：

> "我们对每条标注强制打来源标记，分四类：仿真真值 sim_GT、强模型伪标签 pseudo_GT、人工精标 human_GT 和产线模型输出 model，这是总线 AnnotationSet 的硬字段。质检是四级漏斗：规则全量校验、模型置信度加双模型互检、按来源和置信度分层人工抽检、最后小规模人工精标做 Golden Set 和 Hold-out。对应的三套 GT 分工不能混——仿真真值做大规模迭代、伪 GT 补真实域、人工 Hold-out 冻结只做最终结论。门禁上分层抽检一致率 95%、通吃率 90%、人工介入率压到 10% 以下，违规率必须是 0，全批拦截。两条最硬的红线：来源不能混标，模型伪标签不能冒充人工真值；互检必须用不同方法族的独立失败模型，否则检不出共性错误。"
