# 模型卡 01：手部重建 · HaWoR

> 02-生产域 模型卡系列第 1 张（**示例卡**）。定位：管线「手部检测与重建」算子的标杆模型。承接 [算子设计-01 §4 手部算子](../算子设计/算子设计-01-业内通用算子全集总览.md)；素材底稿 = [调研笔记-01 场景 A](../../92-调研笔记/调研笔记-01-具身数据处理模型-场景化选型与管线结合.md)。

## 核实状态（2026-10-17）

- ✅ 出处：CVPR 2025 Highlight，上海交大 + 帝国理工（Jinglei Zhang 等）
- ✅ 指标：全局轨迹 ATE 3.36mm、PA-MPJPE 达 SOTA（论文报告，见 §8）
- ❓ 待补：目标 GPU 上的实测耗时 / 显存 / 吞吐（待跑 benchmark，按算子设计-06 成本口径回填）
- ⚠️ 口径：生产互检「Hamer + HaWoR」为示例性写法（算子-01 核实状态）

## 1. 定位与算子位置

- **任务**：从第一视角（egocentric）视频恢复**世界坐标系下的 3D 手部运动**（MANO 参数化）
- **算子位置**：生产域 · L2 感知结构化 → 手部检测与重建算子
- **坐标系**：中间产物在相机系，最终手部轨迹经相机轨迹抬升到**世界系**
- **定位**：该任务目前最具代表性的开源方案，手部结构化通道标杆；相对"分件路线"（WiLoR/YOLO 检测 → MANO 拟合 → Masked DROID-SLAM 平滑），它是**自带检测+MANO+ego SLAM+出视野补全的一体化升级路线**

## 2. 模型原理（一句话 + 三模块）

- **核心思想**：第一视角下相机与手同时运动，直接回归世界坐标病态 → **解耦**
  1. **手部检测与跟踪 → 相机空间 MANO 重建**：帧间检测生成 tracklet（手性 + 每帧置信度），Transformer 逐帧回归 MANO（β 形状 / θ 姿态）
  2. **自适应第一视角 SLAM（adaptive egocentric SLAM）**：针对第一视角快速运动 / 低视场改进鲁棒性，估计世界系相机轨迹
  3. **运动补全网络（motion infilling）**：手短暂出视野（out-of-view）时补全轨迹
- **组合逻辑**：相机空间手部轨迹（①）+ 世界空间相机轨迹（②）= 世界空间手部运动；③ 兜底出视野
- 与管线「相机位姿回注手部抬升世界系」同构——**相机轨迹是公共坐标系**

## 3. 输入 / 输出规格

- **输入**：
  - L1 规范化 RGB 帧序列（统一帧率 / 分辨率 / 去畸变）+ 时间戳
  - 相机内参（AR/头显提供；互联网 ego 视频无内参，需 GeoCalib 前置）
- **输出（每帧、每手）**：
  - 相机系 **54 维** = 腕位 wrist(3) + 旋转 6D(6) + MANO 关节(45)；MANO β(10) 形状 / θ(45) 姿态
  - 世界系：`world = camera_to_world @ hand_cam`
  - 手部 mask 二值图时序（喂分割/跟踪）
- **字段命名建议**：`hand_joint_cam[T,45]`、`hand_wrist_cam[T,3]`、`hand_rot6d_cam[T,6]`、`hand_wrist_world[T,3]`

## 4. 管线位置与上下游

- **上游 / 回注**：
  - L1 帧流 + 内参（无内参走 GeoCalib）
  - 深度模块回注 **FoV**（手部 2D 投影约束）
  - 相机位姿模块回注 **camera_to_world**（**仅后处理坐标变换，不参与 MANO 拟合**）
- **下游**：
  - 手部 mask → 分割/跟踪算子（遮挡屏蔽）
  - 世界系手部轨迹 → 语义层（动作分割的腕速曲线）
  - 尺度锚 scale_factor → 可给物体 6DoF 提供初值
- **组合**：与分割（手/物 mask）+ 6DoF（物体位姿）组合 → 手-物交互结构化（接触边界 + 相对位姿），这是操作数据最有价值的部分

## 5. 指标与资源

- **精度（论文报告）**：
  - 全局轨迹 **ATE 3.36mm**（世界系轨迹对齐误差）
  - PA-MPJPE 达 SOTA
  - 首个在真实世界系重建第一视角手部运动的方法
- **资源**：
  - 检测 + MANO 回归为 GPU 推理；SLAM 部分可 CPU 化 → 匹配 L2 GPU Actor 池（GPU Actor 常驻 + SLAM 旁路）
  - 长序列需切段 + 段间轨迹拼接（与 MegaSaM 同理）
  - 实测耗时 / 显存 / 吞吐：待跑 benchmark

## 6. 选型与替代

- **适用**：第一视角手-物操作数据、需要世界系手部轨迹
- **替代 / 互检**：
  - **WiLoR**（端到端手部定位+重建，出朝向初值）
  - **Hamer**（手部 MANO 回归，生产常见，独立失败模式 → 双模型互检）
  - **FrankMocap**（轻量，精度低）
  - **分件路线**：YOLO/WiLoR 检测 → MANO 拟合 → Masked DROID-SLAM 时序平滑（不修改 β）
- **降级**：算力受限/实时性要求高 → WiLoR 或 Hamer；仅做相机系质检 → 更轻的 2D 方案

## 7. 失效模式与红线

- **失效**：
  - 快速运动、严重遮挡（手被物体大面积遮挡 → 关键点失效 → MANO 崩坏）
  - 手出视野（补全网络缓解但不消除）
  - 极端光照下检测退化
  - 长视频漂移（需切段拼接）
- **红线**：
  - **camera_to_world 禁止回灌进 MANO 拟合优化回路**（仅后处理），否则把 SLAM 漂移放大到 MANO 参数
  - 尺度链：MoGe 深度 → SLAM 相机轨迹 → 手部抬世界，每步漂移，不能假设天然对齐，L2 出口做几何一致性校验
  - 域错配：输入帧率 / 分辨率 / 内参与训练口径不一致需先校验

## 速讲话术（30 秒）

> "HaWoR 解决第一视角手部在世界坐标系的重建。第一视角下相机和手同时运动，直接回归世界坐标是病态的，所以它先在相机空间做 MANO 重建，再用一个适配第一视角的 SLAM 估计世界系相机轨迹，两者组合抬升到世界系，手出视野用运动补全兜底；论文报告全局轨迹 ATE 3.36mm。工程上它 GPU 推理为主、可切段流式，我会和 Hamer 做双模型互检。它和 MegaSaM 的协同点在于：相机轨迹是公共坐标系，场景重建给出手部重建的坐标系基准。"
