# 模型卡 05：物体 6DoF 位姿 · FoundationPose

> 02-生产域 模型卡系列第 5 张。定位：管线「物体 6DoF 位姿」算子的标杆模型，物体通道的结构化核心。承接 [算子设计-01 §4 物体 6DoF 行](../算子设计/算子设计-01-业内通用算子全集总览.md)；素材底稿 = [调研笔记-01 场景 E](../../92-调研笔记/调研笔记-01-具身数据处理模型-场景化选型与管线结合.md)。

## 核实状态（2026-10-17）

- ✅ 出处：CVPR 2024 **Highlight**，NVIDIA 出品，RGB-D **零样本** 6DoF 跟踪
- ✅ 量级口径：与 [算子设计-06](../算子设计/算子设计-06-算子成本模型.md) 估算表一致（GPU 100ms–1s/帧，依赖跟踪长度）
- ❓ 待补：**少样本免 CAD 模式的最低样本数与鲁棒边界**（调研笔记-01 §6 待确认项）；目标硬件实测耗时 / 显存（待跑 benchmark，按算子设计-06 成本口径回填）

## 1. 定位与算子位置

- **任务**：跟踪已知物体的 **6DoF 位姿轨**（3 平移 + 3 旋转，齐次矩阵表示）
- **算子位置**：生产域 · L2 感知结构化 → 物体 6DoF 位姿算子（`op-per-6dof`）
- **坐标系**：**优化求解全程在相机系**，输出 `obj_pose_cam[T,4,4]`；世界系 = camera_to_world 后处理抬升
- **定位**：物体通道结构化核心——手-物相对位姿、物体运动轨迹都从它出发；6DoF 领域 SOTA 级开源

## 2. 模型原理（一句话 + 两模式）

- **核心思想**：RGB-D 输入下的**零样本** 6DoF 位姿估计与跟踪——不针对特定物体训练，靠渲染-比对式推理泛化到新物体
  1. **CAD 模式**：给物体 CAD 模板，零样本 6DoF 跟踪（工业最常见——夹爪/工具/零件有模型）
  2. **少样本免 CAD 模式**：无 CAD 时 test-time 优化，用少量参考图构建物体模板再跟踪
- 学术出处：CVPR 2024 Highlight（NVIDIA Labs）

## 3. 输入 / 输出规格

- **输入**：
  - L1 RGB 帧
  - ④ MoGe 深度图（组成 **RGB-D** 之 D 通道，[模型卡 03](03-单目深度-MoGe+DepthAnythingV2.md)）
  - ⑤ 物体 mask 时序 + 接触点（**ROI 裁剪**，[模型卡 04](04-分割跟踪-SAM2+TAPIR.md)）
  - ③ `camera_to_world`（**仅后处理坐标抬升，不参与 6DoF 优化求解**，[模型卡 02](02-相机位姿-MegaSaM.md)）
  - 初值：可接② HaWoR 的尺度锚 `scale_factor`（[模型卡 01](01-手部重建-HaWoR.md)）
- **输出**：`obj_pose_cam[T,4,4]`；世界系 = `camera_to_world @ obj_pose_cam`
- **字段命名建议**：`obj_pose_cam[T,4,4]`、`obj_pose_world[T,4,4]`、`obj_id` + `track_id`

## 4. 管线位置与上下游

- **上游 / 回注**：深度（D 通道）、mask（ROI）、相机矩阵（后处理）、尺度锚（初值）——L2 里**汇聚输入最多的算子**（PipelineSpec 中它的 upstream 跨列引用 depth + cam + 帧流）
- **下游**：
  - 物体世界系位姿轨 → L2 出口四层结构化轨迹的"物体层"
  - 与②手部轨迹组合 → **手-物相对位姿**（操作数据最有价值的结构：抓取、搬运、交互几何）
  - L3 动作分析（物体状态变化 = 动作阶段的物证）
- **组合**：它是 ④深度/⑤mask/③矩阵/②尺度四路汇聚的终点，也是 L2 出口质检（世界系一致性校验）的受检方之一

## 5. 指标与资源

- **量级**（[算子设计-06](../算子设计/算子设计-06-算子成本模型.md) 估算表）：GPU 100ms–1s/帧，**依赖跟踪长度**（长跟踪显存与耗时同步涨）；实测：待跑 benchmark
- **质检指标**：物体跟踪成功率、位姿时序跳变幅度（跳变 = 跟踪丢失/重匹配的信号）
- **资源**：GPU 推理（L2 感知池 GPU Actor）；需按物体数 × 跟踪长度估算池规模

## 6. 选型与替代

- **适用**：有 RGB-D + 物体可辨识（CAD 或少样本可建模板）的零样本跟踪——新物体不停改模型
- **替代 / 互检**：
  - **MegaPose**：6DoF 同档常见替代（工程界并列常用）
  - 检测式位姿（YOLO + 2D 框 + 逆投影）：轻量但只有粗位姿，无 6DoF 旋转
- **降级**：无深度通道（纯 RGB）→ 退化到 2D 跟踪 + 人工/规则补位姿；无 CAD 且少样本不达标 → 只出 mask 轨不做 6DoF（欠账标记，进回流补采）

## 7. 失效模式与红线

- **失效**：
  - 物体**遮挡 / 出帧** → 跟踪跳变、丢失（质检指标"跳变幅度"就是抓它）
  - **深度误差直接放大位姿误差**（D 通道来自单目估计而非深度相机，误差不衰减地进优化）
  - 少样本模式下模板质量差 → 首帧即偏
- **红线**：
  - **camera_to_world 不参与 6DoF 优化求解**（仅后处理）——回灌 = 把 SLAM 漂移放大进物体位姿
  - 物体世界坐标**完全依赖③矩阵**：③错则物体层全错，且无独立矫正手段——出口一致性校验必须含物体层
  - 深度→位姿的误差传导系数大，弱纹理/反光物体的深度坏帧要先经④互检门再进本算子

## 面试话术（30 秒）

> "物体 6DoF 用 FoundationPose，CVPR 2024 Highlight，NVIDIA 出品，核心能力是 RGB-D 零样本跟踪——不用针对每个物体训练，有 CAD 用 CAD 模式，没有就用少样本 test-time 优化建模板。它在管线里是汇聚输入最多的算子：MoGe 深度当 D 通道、分割 mask 做 ROI、HaWoR 的尺度锚给初值、相机矩阵做后处理抬世界系。优化全程在相机系，出来再乘 camera_to_world 到世界系，和手部轨迹组合出手-物相对位姿，这是操作数据最有价值的结构。两个工程红线：深度误差会直接放大成位姿误差，坏帧要先过互检门；相机矩阵绝不进优化回路，只做后处理。遮挡和出帧造成的跳变我们用位姿时序跳变幅度这个指标来抓。"
