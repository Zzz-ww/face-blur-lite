## 1. 定位与算子位置

- **任务**：为原子动作片段生成**结构化语言指令**，并对多源指令做**语义标准化**（消歧、统一术语、子任务标注）
- **算子位置**：生产域 · L3 语义标注 → 语言指令生成 / 语言标准化 / 子任务标注算子（`op-sem-*`）
- **坐标系**：不涉及 3D 坐标系——但**片段边界与物理依据来自 L2 世界系产物**（腕速曲线、mask/接触边界、时间戳对齐）
- **定位**：语言通道的引擎；动作分割（腕速曲线局部极小值切分，CPU 规则）是它的**前置算子**，不是它的一部分

## 2. 模型原理（一句话 + 三步流程）

- **核心思想**：规则切分定边界、VLM 填语义——确定性部分（切分）与生成性部分（指令）分治
  1. **前置动作分割**（规则，CPU UDF）：腕部速度曲线平滑 → **局部极小值切分**原子动作片段（工业主流口径）
  2. **VLM 逐片段生成**：片段视频帧 + L2 物理依据（接触边界/物体 mask）→ 结构化指令 JSON
  3. **语义标准化 / 指令重写**：消除不同采集源/标注员的表达差异，统一术语与句式（GigaBrain 同构：LLM 辅助指令重写 + 子任务标注）
- **代表模型**：Qwen2.5-VL（开源主流）、LLaVA、GPT-4o（API）

## 3. 输入 / 输出规格

- **输入**：
  - 原子动作片段（帧区间 + 抽关键帧）
  - L2 结构化产物：腕速曲线、手/物 mask + 接触边界、物体状态变化（物理依据，降低 VLM 幻觉）
- **输出（设计通识，逐片段）**：结构化 JSON——
  - `language_instruction`（标准化指令文本）
  - 片段边界 `[t_start, t_end]`（继承自切分算子，VLM 不改写边界）
  - 动作标签 / 子任务标签（层级：原子动作 → 子任务 → 长任务）
  - 来源标记 `label_source: model`（对齐[总线 §4.1](../../00-总体架构/README.md) AnnotationSet 字段——VLM 产出属 model 来源，与 sim_GT/pseudo_GT/human_GT 区分）
- **字段命名建议**：`instruction_json[T_seg]`、`action_label[T_seg]`、`subtask_label[T_seg]`

## 4. 管线位置与上下游

- **上游**：L2 世界系结构化轨迹（四层产物，时间戳对齐）；动作分割算子（`op-sem-cut` 前置）
- **下游**：
  - `AnnotationSet`（语言通道部分）→ 治理域门禁（G 门抽检）
  - L4 封装：指令写入 LeRobotDataset（`language_instruction` 字段是 VLA 训练直接消费品）
  - 指令质检失败片段 → 回流（人工复核 / 重切分 / 重生成）
- **组合**：与检测/分割（场景描述）、多阶段 QC（GigaBrain 式过滤）串联；跨源数据集合并时标准化环节必跑

## 5. 指标与资源

- **质检指标（设计通识）**：指令-片段一致性抽检一致率（人对齐 G 门分层抽检）、可执行性（指令能否唯一对应动作）、标准化后术语收敛率
- **资源**（[算子设计-06](../算子设计/算子设计-06-算子成本模型.md) 估算表）：GPU/API **秒级每片段**，或按 token 计费——成本随片段数线性涨，切分粒度直接决定成本
- **量级实测**：待跑 benchmark（开源 VLM 本地推理 vs API 单价对比，按算子设计-06 成本口径回填）

## 6. 选型与替代

- **适用**：批量语义标注 + 标准化；开源部署（数据不出域）优先 Qwen2.5-VL / LLaVA
- **替代 / 互检**：
  - **Qwen2.5-VL / LLaVA**：开源可控、可微调，数据合规友好（具身数据常涉隐私，出域前必须本地推理）
  - **GPT-4o 类 API**：质量上限高，但数据出境/成本/速率受限——适合小规模试点或 Golden Set 生成，不适合全量
  - 规则模板：高频固定动作（已知动作库）用模板直接生成，VLM 只兜长尾——成本大降
- **降级**：成本敏感 → 抽样 VLM + 模板补全；质量敏感 → 双 VLM 互检（开源一个 + API 一个）

## 7. 失效模式与红线

- **失效**：
  - **片段边界错 → 指令必错**（切分错误的片段语义不完整）——边界质量是上游责任，本算子不背锅但要检测
  - VLM 幻觉（描述不存在的动作/物体）——用 L2 物理依据做 grounding 约束 + 抽检门
  - 长任务漏子任务、跨源术语不收敛
- **红线**：
  - **label_source 必须如实标记 model**——VLM 指令是模型产出，禁止与人工标注混标（血缘/质检口径都依赖此字段，对齐总线 AnnotationSet）
  - 隐私数据（人脸/环境信息）进 API VLM 前必须脱敏前置（L1 脱敏算子顺序不可倒置）
  - 指令改写不得改变动作语义（标准化 = 换表达不换含义），改写前后做语义等价抽检
