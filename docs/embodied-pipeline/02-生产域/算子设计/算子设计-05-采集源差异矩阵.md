## 1. 四源概述

| 源 | 数据特点 | 结构化主线 |
| --- | --- | --- |
| 第一视角 ego（AR/头显/互联网） | RGB 视频，无本体真值 | **视觉重建**（检测/手部/位姿/深度） |
| 遥操作（双臂/单臂） | 关节流 + 相机，**有本体真值** | 真值直读，视觉重建可跳过 |
| 仿真 | 渲染 + **自带 GT** | GT 旁路，跳过感知重建 |
| 动捕/传感器 | marker/IMU/深度直读 | 传感器直读，视觉重建可跳过 |

## 2. 算子适用矩阵（行 = 算子，列 = 源）

| 算子 | 第一视角 | 遥操作 | 仿真 | 动捕 |
| --- | --- | --- | --- | --- |
| 时间同步 / 标定 | ✔ 必需 | ✔ 必需 | ✔ 必需 | ✔ 必需 |
| 帧提取 / 去畸变 | ✔ | ✔ | ✔ | ➖ |
| 脱敏前置 | ✔ | ✔ | ➖（合成无隐私） | ➖ |
| 目标检测 / 分割 | ✔ | ○ 辅助 | ➖（GT 直出） | ○ 辅助 |
| 手部重建 | ✔ 核心 | ○ 校验用 | ➖ | ○ 校验用 |
| 相机位姿 | ✔ 核心 | ✔（手眼标定即可） | ✔（引擎已知） | ✔ |
| 单目深度 | ✔ | ○ | ➖（GT 深度） | ○ |
| 物体 6DoF | ✔ | ✔（真值） | ➖（GT） | ✔（真值） |
| 动作分割 | ✔ | ✔ | ✔（可自动） | ✔ |
| VLM 指令生成 | ✔ | ✔ | ✔ | ✔ |
| 清洗/去重/合规 | ✔ | ✔ | ✔ | ✔ |
| 格式封装 | ✔ 统一出口 | ✔ | ✔ | ✔ |

> ✔ 保留　○ 可选（替换为真值校验）　➖ 跳过

## 3. 各源管线裁剪示例

- **第一视角**：全链路（视觉重建主线）
- **遥操作**：`采集 → 同步/标定 → 真值直读 → 动作分割 → VLM → 清洗 → 封装`（跳过 L2 视觉重建，手部/位姿仅作质检互检）
- **仿真**：`采集 → GT 直出（深度/位姿/分割全有）→ 动作分割（可自动）→ 指令 → 清洗 → 封装`
- **动捕**：`采集 → 传感器直读 → 动作对齐 → 指令 → 清洗 → 封装`

**统一出口**：四源最终都封装为同一样本 Schema（LeRobot v2/v3），下游训练无感知。
