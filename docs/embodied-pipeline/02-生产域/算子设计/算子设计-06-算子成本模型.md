## 1. 成本口径

| 指标 | 定义 |
| --- | --- |
| GPU 秒/样本 | 单样本消耗 GPU 时长（含加载摊销） |
| CPU 秒/样本 | 规则算子单样本耗时 |
| 吞吐 | 样本/小时（分阶段） |
| 单小时数据成本 | 总资源成本 / 产出有效数据小时数 |

## 2. 算子成本量级表（估算，示例性）

| 算子 | 量级 | 说明 |
| --- | --- | --- |
| 规则算子（帧提取/去重/校验） | CPU 毫秒级/帧 | 便宜，可大规模并行 |
| 目标检测 / 分割 | GPU 10–100ms/帧 | 批量推理 |
| 单目深度 | GPU 10–100ms/帧 | 模型相关 |
| 手部重建 HaWoR | GPU 秒级/样本 | 含跟踪/回归 |
| 相机位姿 MegaSaM | GPU ~13s/样本（第三方 OpenReview 对比，已核，见[模型卡 02](../模型卡/02-相机位姿-MegaSaM.md)） | 长视频需切段，成本大头 |
| 物体 6DoF FoundationPose | GPU 100ms–1s/帧 | 依赖跟踪长度 |
| VLM 指令生成 | GPU/API 秒级/片段 | 或按 token 计费 |
| 视频编码/封装 | CPU 秒级/样本 | 一次性 |

## 3. 省钱策略（按优先级）

1. **规则前置**：去重/过滤/完整性校验先跑（CPU 便宜），拦截无效样本再进 GPU 环节
2. **分层采样**：对海量原始数据先抽样评估，再决定全量处理
3. **模型降级**：成本敏感环节用轻量替代（跨档替换为主，如位姿 MegaSaM→COLMAP；同档替换需实测）
4. **批处理与复用**：GPU Actor 常驻避免反复加载；同段先验结果复用
5. **缓存**：去畸变/脱敏等确定性算子结果按 hash 缓存
6. **成本监控**：每算子 GPU 秒/样本入监控，异动告警
