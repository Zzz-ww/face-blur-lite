## 02 · 安全合规（RBAC / 作业准入钩子 / 审计日志 / 脱敏执行强制）

**定位一句话**：六域共用的**执行强制层**——权限（RBAC）、作业准入（合规检查钩子）、审计（全链 append-only）、脱敏执行（规则在治理 07，本篇管落地强制）。

**边界（写进文档）**：
- 管：角色权限矩阵（附录 C 五角色细化 + 数据集/版本/作业级权限）、作业准入三合一钩子（RBAC 授权 + 合规检查 + 配额检查，提交 PipelineSpec 时执行）、审计日志基础设施（全链留痕、不可篡改、合规取证）、脱敏执行强制（前插调度与覆盖校验）
- 不管：合规规则怎么定义（治理 07 策略即代码，SSOT）、配额怎么调度（管控 02，SSOT）、脱敏算子实现（生产域算子库）
- **核心纪律：规则在治理 07，横切只执行强制——本篇不当第二裁判，也不重写规则**

**分块建议（§3-§6）**：
1. **RBAC 权限模型**：角色 × 域 × 操作矩阵（以附录 C 为底表扩展：谁能在哪个域做什么——数据工程师编辑算子/提交作业、算法导出评测、标注台标注质检、运维调度配额、合规审批脱敏/审计）；数据集/版本级权限（资产域目录权限联动）；最小权限原则（默认拒绝，按需授权）；权限变更留痕（联动审计）
2. **作业准入钩子**：提交 PipelineSpec 时三合一检查（权限够不够 + 合规标记齐不齐 + 配额有没有）；**不合格不下发**（拦截在控制面，不让违规作业进队列——最省的一刀，对齐算子-06 规则前置思路）；准入结果入审计
3. **审计日志**：全链 append-only（谁、何时、对哪个数据集/版本/作业、做了什么——覆盖操作/版本晋升/数据导出/权限变更/门禁审批）；不可篡改（合规取证，删除/覆盖需留痕）；与 01 可观测性日志中心审计分仓联动（观测平台存，治理 07 §8 出报告）
4. **脱敏执行强制**：脱敏规则与前置纪律在治理 07 §5（脱敏前置链路纪律）；本篇管执行强制——DAG 中脱敏算子的前插位置强制（可在 02-生产域预处理后/结构化前，联动算子全集）、覆盖校验（脱敏漏网 = P0 告警，联动 01）、脱敏版本与数据版本三锁联动（算子-04）
5. （可选）**合规门与发布流程**：版本晋升前的合规审批（治理 07 合规门）、出境控制点执行（治理 07 §7 工程控制点落地为检查项）

**红线方向（参考，写时细化成 6 条）**：
1. 规则不重定义（SSOT 治理 07）
2. 最小权限默认拒绝
3. 审计不可篡改（append-only）
4. 准入不合格不下发（拦截在控制面）
5. 脱敏漏网 P0 硬告警（不静默）
6. 权限变更/门禁审批必留审计痕

## 03 · 多租户与计量计费（项目模型 / 计量 / 预算治理 / 配额治理视图 / 隔离）

**定位一句话**：六域共用的**计量与预算治理层**——谁用了多少算力/存储/带宽、花了多少钱、预算怎么管；配额执行归管控域，本篇管「配额从哪来（预算）、花了多少（计量）、谁买单（账单）」。

**边界（写进文档）**：
- 管：项目/租户模型（项目 = 计费与配额单元）、计量（算子成本聚合：GPU 秒/样本 → 数据集 → 项目；存储/带宽/标注人力）、预算治理（申请/审批/超支熔断）、配额治理视图（预算 → 管控配额 → 用量 → 账单的闭环）、租户隔离（数据权限 + 命名空间）
- 不管：配额怎么调度（管控 02 Kueue/ElasticQuotaTree，SSOT）、成本怎么算（算子-06，SSOT）、权限矩阵（本域 02，SSOT）
- **核心纪律：计量口径只聚合不重定义（算子-06 是成本 SSOT）；配额执行不越界（管控域调度）——本篇是「账房」，不是「调度器」**

**分块建议（§3-§6）**：
1. **项目/租户模型**：项目 = 计费与配额单元（数据集目录/作业/模型版本归属）；多租户层级（平台 → 组织/团队 → 项目）；与 RBAC 联动（项目内角色继承，联动 02）
2. **计量**：算子成本聚合（GPU 秒/样本 × 单价，算子-06 SSOT）→ 数据集成本 → 项目成本；存储计量（湖仓冷热分层用量，资产域 04）；带宽计量（上云/导出流量）；标注人力（人工标注小时，联动标注体系）；**计量与账单对账**（成本视图准确率，联动 01）
3. **预算治理**：项目预算申请/审批流（配额来源 = 预算——配额不是免费的）；超支熔断（预算耗尽 = 暂停新作业，联动管控配额——硬约束不是建议）；预算按项目/周期核算
4. **配额治理视图**：预算 → 管控域配额（Kueue ElasticQuotaTree 执行）→ 实际用量 → 项目账单的**闭环视图**；配额调整走审批（谁加的配额、为什么、留审计痕）
5. **租户隔离**：数据隔离（数据集目录权限 + 版本权限，联动 02 RBAC）、作业隔离（命名空间/资源池，管控域执行）、**隔离不可绕过**（越权访问 = P0 事件，联动 01 告警）

**红线方向（参考，写时细化成 6 条）**：
1. 计量口径 SSOT 不重复（算子-06）
2. 配额执行不越界（管控域调度，本篇只治理）
3. 超支熔断是硬约束（不手软）
4. 配额调整必审批留痕
5. 租户数据隔离不可绕过（越权 = P0）
6. 账单必对账（计量与真实成本一致）
