## 第 2 篇：`02-下游评测执行与L4收益.md`

**主题**：L4 下游评测的**执行面**（标准在治理 04，本篇是考生/执行者——"考务方不代考，本篇去考"）。

**定位句**：治理 04 定 L4 标准（指标/GT/频率/阻断性），本篇是 L4 的执行者——评测任务怎么编排、评测集怎么取数（白名单+隔离）、benchmark 怎么选型、任务成功率怎么采、消融实验怎么做、EvaluationReport 怎么产出。

**边界（不管）**：L1–L3 评测（各在自域）；评测标准与报告归档（治理 04）；回归基线管理（治理 05）；训练消费与边界（本域 01）；badcase 回流（本域 03）。

**必须覆盖的正文要点**：

1. **评测取数**：L4 评测集 = test/hold-out（白名单取数，资产域 05 §7 / 治理 06 §5）；评测任务也要版本精确引用、也要样本快照（可复现的评测）；评测集隔离红线（Golden/Hold-out 绝不进训练）在评测侧的执行。
2. **评测任务编排**：评测即消费（复用本域 01 的取数/校验/就绪纪律）；评测任务通过管控域调度（RayJob）；GPU 资源与训练共享配额（管控 02 多租户）；评测与训练的调度优先级（评测短任务、训练长任务）。
3. **benchmark 选型与对比口径**：真机评测（少量、贵、最终结论）vs 仿真任务套件（大量、低成本、高频）的分工（对齐治理 04 §4 三套 GT 在 L4 的用法）；对比基线从哪来（治理 05 基线注册表）。
4. **任务成功率采集**：多 episode 平均、置信区间；域间差距（仿真 vs 真机）采集上报——监测归治理（治理 04 §7 域间差距），本篇提供数据。
5. **消融（ablation）实验执行**：加/减数据子集 → 下游任务成功率 Δ → 边际收益（治理 04 §5）；实验设计纪律：对照组、重复次数、数据子集定义必须精确引用版本与样本快照；**消融结论的效力边界**——单次消融是小样本证据，多版本/多任务交叉验证才可信。
6. **EvaluationReport 产出**：字段对齐治理 04 §6（l1~l4/回归基线/回流建议），本篇产出 L4 部分与 recommendations；报告进治理 05 发布物料。
7. 指标表：评测覆盖率、评测可复现率（样本快照）、白名单越权 0、报告及时率（Golden 回归 ≤24h 待标定）、消融实验完成率。

## 第 3 篇：`03-Badcase回流闭环.md`

**主题**：Badcase 从**发现到关闭**的全生命周期——消费域是 badcase 的产生源与回流发起方，治理域定位决策，生产/接入域执行修复，治理域回归验证。

**定位句**：闭环的消费侧起点——评测/训练中发现 badcase → 打标分类 → 血缘定位 → 提交回流（EvaluationReport+Badcase 契约）→ 跟踪回流任务 → 验证修复效果，驱动数据飞轮（总线 §6 #8、P4 智能闭环）。

**边界（不管）**：缺陷分类规则与工单机制（治理域）；血缘定位手段（治理 02）；回归判定（治理 05）；补采执行（接入/生产域）。

**必须覆盖的正文要点**：

1. **Badcase 定义与发现源**：定义（评测失败样本/低置信/重建失败/语义错误等）；发现源矩阵：L4 评测失败、L1 抽检、人工标注复核、训练损失异常、线上反馈——各源产出的 badcase 形态不同。
2. **打标与分类**：badcase 打标（缺陷类型/严重度/所属算子）；分类决策树：数据问题（补采/重跑）vs 模型问题（算子升级）vs 标注问题（重标注）——分类决定回流方向。
3. **血缘定位**：从 badcase 样本回溯三锁（数据版本/算子版本/模型版本）——定位到具体算子与数据版本（治理 02 §4）；blast radius 评估（治理 05 §6 精神：影响哪些下游版本）。
4. **回流契约与流转**：消费→治理契约（总线 §4.2：回流标记 + 血缘定位）；回流任务下发（治理→生产/接入：缺陷分类 + 目标算子）；回流样本作为新数据进生产域走 badcase 修复算子与 G 门复检（G0–G6 全程）。
5. **回归验证与关闭**：修复后版本上 Golden Set 回归（治理 05）+ 原 badcase 用例复测（badcase 进回归用例库——防倒退考题之一）；badcase 关闭标准（复测通过 + 回归无倒退）；**badcase 样本本身不得进训练集复用为评测**（防假闭环：修过的题不能当新考题，除非走评审进 Golden 受控扩充）。
6. **P4 智能闭环演进**：从人工标记 → 规则自动标记 → 评测驱动自动补采（L4 反哺数据迭代）；闭环指标（回流周转、badcase 关闭率、复发率）。
7. 红线：badcase 必须带血缘定位才能回流（无定位=不可执行）；修复必须回归验证才关闭；修过的题不当新考题（防假闭环）。
