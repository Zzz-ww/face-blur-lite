# 必须覆盖的内容（已核实事实，直接采信）
1. 总原则：自动标注跑全量（label_source=model/pseudo_GT），人工只做「提示 + 抽检 + 修正 + 精标」；自动率（通吃率）是核心 KPI，人工是最贵环节。
2. 人机协同闭环：自动全量 → 置信度门/双模型互检 → 低置信度与分歧件路由人工队列 → 人工修正 → 回流 → 模型/规则迭代（形成回路）。
3. 人工不可替代的 5 类任务：
   - 首帧提示：SAM2 冷启动的首帧 mask（ego 用 EgoHOS，开域用 Grounded-SAM 文本提示，模型卡 04）；
   - 低置信度/互检分歧件复核（置信度示例阈值 <0.6，见算子-02 §10 手部示例）；
   - 少样本 6DoF 建模板（FoundationPose 少样本免 CAD 模式，模型卡 05）；
   - VLM 指令校对/改写与子任务边界确认（模型卡 06；GigaBrain 同构）；
   - Golden Set / 真实 Hold-out 精标（最终标尺，只评测不训练）。
4. 标注台（平台）能力：任务队列与智能路由（按置信度/来源/类别派单）、预标注（模型先出 pre-label，人工只修正不从零标，效率关键）、多类标注界面（2D mask/关键点、3D 6DoF 位姿、动作片段切分、指令校对）、多人协同与进度、标注员管理与一致性（IAA / Cohen's Kappa，建议 Kappa≥0.8 为团队目标，标注为团队自定非硬标准）、操作留痕。
5. 效率与成本：人工介入率、单位标注耗时/吞吐、预标注采纳率；用规则前置 + 预标注把人工压到长尾（与算子-06 成本模型呼应）。
6. 隐私前置：标注员看到的画面必须已过人像脱敏（op-pre-desensitize / op-des-audit），人工标注环节不得先于脱敏。
