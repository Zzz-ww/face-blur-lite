# 各卡素材映射与已核实事实（直接采信，避免重复劳动或编造）
- 02-相机位姿-MegaSaM：素材=调研笔记场景 B。MegaSaM = CVPR 2025 Best Paper Honorable Mention；第三方 OpenReview 对比表约 13s/样本、约 7GB 内存，长视频需切段（https://openreview.net/forum?id=oBOVYRRSy2）。它是「坐标系枢纽」，输出 camera_to_world[T,4,4]；分支：有内参直接 MegaSaM/DROID-SLAM，无内参 GeoCalib 前置；静态场景备选 COLMAP。先验=MoGe 深度（仅初始化/约束，不绑定尺度）。红线：camera_to_world 只用于后处理抬升，禁止回灌进手部/位姿优化。
- 03-单目深度-MoGe+DepthAnythingV2：素材=场景 C。MoGe = CVPR 2025 Oral（含 MoGe-2），metric 真实尺度、主尺度基准；Depth Anything V2 是相对深度/视差，做互检。输出深度图+点云+法线+FoV，5 路分发：深度喂相机位姿、FoV 反哺手部、深度做 FoundationPose 的 D、与 DAv2 互检、法线/点云出产物。红线：MoGe 绝对尺度在弱纹理/遮挡下仍漂移，不可无条件信任；尺度链误差会传导给相机轨迹/手/物体。
- 04-分割跟踪-SAM2+TAPIR：素材=场景 D。首帧冷启动二选一：ego 视角 EgoHOS，开域未知物体 Grounded-SAM（文本 prompt）→ SAM2 时序传播 → TAPIR 稠密点轨迹补接触边界。输出手/物 mask 时序轨 + 接触边界。关键：首帧 mask 失效则 SAM2 全时序崩坏，需设首帧质检门；TAPIR 是 2D 点，需结合深度+外参才得 3D 接触点。指标：mask 时序 IoU 衰减率、接触点有效性。
- 05-物体6DoF-FoundationPose：素材=场景 E。FoundationPose = CVPR 2024 Highlight，RGB-D 零样本 6DoF 跟踪，CAD 模式/少样本免 CAD 两模式。输出 obj_pose_cam[T,4,4] → 经 camera_to_world 抬世界系（仅后处理）。失效：遮挡/出帧跳变、深度误差直接放大位姿误差。备选 MegaPose。
- 06-语义标注-VLM：素材=算子-01 §5、§10 + GigaBrain 指令重写/子任务标注。主流程：腕速曲线平滑→局部极小值切分原子动作→VLM 生成结构化指令 JSON。代表模型 Qwen2.5-VL / LLaVA / GPT-4o；语言标准化消除来源表达差异。这张卡允许用业界通识补齐：结构化 JSON 字段（language_instruction、片段边界、动作标签）、prompt 工程、指令质检，但必须在「核实状态」里标注为设计通识，未实测项写「待跑 benchmark」，不得编造模型指标。
