# 05-资产域 · 域分册（数据集资产）

> 上游域：[04-治理域](../04-治理域/README.md) ｜ 下游域：[06-消费域](../06-消费域/README.md) ｜ 输入制品：DatasetVersion（晋升令牌） ｜ 输出制品：**TrainingRelease**

## 1. 域职责

数据集目录（检索/打标/浏览）、统一湖仓存储（原始文件 + 元数据 + 向量）、不可变快照、版本回溯、训练样本快照、冷热分层与 TTL。

## 2. 关键组件

数据集目录服务、湖仓（DLF 式统一管理）、向量检索、快照服务。

## 3. 域间契约

治理 → 资产：`DatasetVersion`（门禁晋升令牌）；资产 → 消费：`TrainingRelease`，准入校验 = **split 隔离 + 防泄漏检查**（[总线 §4.2](../00-总体架构/README.md)）。

## 5. 关键机制与质量门

不可变快照：版本发布即冻结，训练引用精确到版本；数据生命周期状态机（Raw → Processing → Quarantined → Validated → Published → Deprecated/Archived）由门禁或治理动作触发（[总线 §6](../00-总体架构/README.md)）；本域做冷热分层与 TTL 降本。
