# 06-消费域 · 域分册

> 上游域：[05-资产域](../05-资产域/README.md) ｜ 下游域：[04-治理域](../04-治理域/README.md)（评测报告与 Badcase 回流） ｜ 输入制品：TrainingRelease ｜ 输出制品：**EvaluationReport + Badcase（回流样本）**

## 1. 域职责

训练消费（数据集导出 → 分布式训练，**训练本身归属模型平台**——平台边界止于 `TrainingRelease`）、下游评测、Badcase 回流驱动数据迭代。

## 2. 关键组件

数据集导出服务、训练衔接（Ray Train/Tune）、下游评测服务、回流通道。

## 3. 域间契约

消费 → 治理：`EvaluationReport + Badcase`，准入校验 = 回流标记 + 血缘定位；治理据此下发回流任务/补采指令（[总线 §4.2](../00-总体架构/README.md)）。
