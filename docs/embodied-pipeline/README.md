## 写作约定

- 域内专题 = 域目录下 `NN-专题.md`，编号即序；跨域内容归属单一域，他域 README §6 放指针
- 图统一放 `docs/assets/`，文档内相对路径引用（`../../assets/…` 或更深一层）
- 每篇专题头部注明定位（承接谁、被谁引用）与核实状态；待写专题先在域 README §4 挂占位行
