## 1. 四层定义（业内标准，用途严禁混淆）

| 集合 | 用途 | 更新频率 |
| --- | --- | --- |
| 训练集 | 模型迭代训练 | 持续增长 |
| 验证集 | 调参、选模型 | 随训练集受控更新 |
| 测试集 | 最终效果验证（一次性结论） | 固定，尽量不更新 |
| 回归集（Golden Set） | 版本回归防倒退 | 固定（受控扩充） |

## 2. 算子层分流（在哪分流、怎么分）

- **分流算子 `op-stat-sample`**（统计采样）在**封装出口**执行，四集一次切分
- 分流维度：源、场景类型、动作类型、本体型号——**分层随机**，保证分布对齐
- 分流后血缘记录 `split=test|train|val|golden`，后续算子（如封装）按 split 分支

## 3. 防泄漏三道防线（算子层强制）

| 防线 | 算子 | 机制 |
| --- | --- | --- |
| 跨集去重 | `op-clean-dedup` / `op-clean-sdedup` | 内容 hash + 语义近重复，**去重在切分前完成** |
| 时间切分 | `op-stat-sample` 参数 | 同一次采集/同一场景**不跨集**（按采集会话/场景 ID 分组切分） |
| 本体/场景隔离 | `op-stat-sample` 参数 | 同本体、同场景数据只落一个集合 |

## 4. 泄漏检测

- 训练-测试相似度监控：抽样计算训练/测试样本 embedding 相似度，超过阈值告警
- 泄漏审计：血缘中 `op-clean-dedup` 的执行记录 + 切分日志交叉核验（血缘 Schema 见 [算子设计-04](算子设计-04-算子血缘与版本三锁.md)）
- 回归门复查：G6 发布前对 Golden Set 与新增训练数据做泄漏抽检

## 5. Golden Set 管理

- 固定版本、长期不变（防过拟合 Golden Set）
- 受控扩充：确需扩充时走评审 + 全量重基准（三锁联动，见 [算子设计-04](算子设计-04-算子血缘与版本三锁.md)）
- 指标基线：每算子/每层质量指标记录基线，回归门对比
