## 1. 版本三锁（联动基线）

| 锁 | 对象 | 变更触发 |
| --- | --- | --- |
| 算子版本 `op_version` | 处理逻辑/参数/代码 | 算子升级 → 全量回归 |
| 数据版本 `dataset_version` | 数据集内容/血缘链 | 数据增删 → 影响下游评测 |
| 模型版本 `model_version` | 感知/VLM 模型权重 | 模型替换 → G2/G3 重评估 |

三锁**绑定发布**：一个数据集发布必须记录三者的精确组合，缺一不可复现。

## 3. 能力

| 能力 | 机制 |
| --- | --- |
| 可复现 | 血缘链 + 配置快照 + hash；确定性算法栈下重跑逐位一致（前提见核实状态） |
| Badcase 定位 | 下游失败样本 → 回溯血缘 → 定位算子/模型版本 → 版本对比 |
| 版本回归 | 三锁任一变更 → G6 Golden Set 回归，不倒退才可发布 |
| 泄漏审计 | 血缘记录去重/切分算子执行痕迹，审计跨集泄漏（详见 [算子设计-07](算子设计-07-四层数据集分流与防泄漏.md)） |
