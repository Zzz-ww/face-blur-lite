# 调研笔记 03：GeoPT 理解与迁移设想

> 调研底稿：《具身数据管线工程笔记》第三章由本篇提炼而成。本篇记录 GeoPT 论文的调研过程：几何提升式预训练范式（思想 + 机制），以及迁移到 L2 感知管线的可行性与切入点。
> 补充来源（2026-10-01）：[VLA-Handbook · GeoPT 条目](https://github.com/sou350121/VLA-Handbook/blob/main/theory/world-model/geopt_lifted_geometric_pretraining_physics_simulation_2026.md)。负迁移动机、数学形式、数据配方与成本数字、风险点消融由该条目补入，此类内容以〔HB〕标注（二手整理，关键数字建议回对 arXiv 原文终核）。

## 0. 调研背景与问题

- GeoPT 要解决的痛点：物理标签（真实速度场/动力学）极度稀缺，纯有监督训练学不动、学不稳。
- 核心思路：把静态几何数据 + 合成动力学拼成可扩展的预训练数据，用自监督先建立物理直觉，再少量真实标签微调。
- 要回答的问题：
  1. 几何提升预训练的具体机制是什么？
  2. "合成动力学 + 几何边界约束"为什么能学到物理直觉？
  3. 为什么"仅静态几何"的自监督不够、甚至可能负迁移？〔HB 补入〕
  4. 学术思想与工程落地之间差什么？
  5. 能否迁移到 L2 感知管线（手部/相机/深度模型的自监督预训练）？

## 1. 核心方法论详解

### 1.1 出发点：静态几何自监督为什么会负迁移〔HB〕

- 下游物理仿真的解场由「几何 G + 动力学条件 S」共同决定；只在静态几何上做自监督（SDF / occupancy / 向量距离重建、掩码重建等），学到的是**与真实物理耦合不一致的空间相关性**——微调时反而被拖累（negative transfer，论文实测会变差）。
- 因此 GeoPT 换的不是 backbone，而是**自监督信号**：把"动力学"以合成速度场的形式放进预训练监督里，让自监督天然携带"边界作用 + 传输耦合"的结构。

### 1.2 三方案对比〔HB〕

| 方案 | 预训练数据 | 监督信号 | 含动力学 | 下游适配方式 | 主要问题 |
|---|---|---|---|---|---|
| 从头训练（scratch） | 物理标签数据（solver 输出） | 拟合物理场 | ✅ | 无 | 标签昂贵、收敛慢、小数据过拟合 |
| 静态几何自监督（native-space） | 海量几何 | SDF/occupancy 等静态特征 | ❌ | 微调到物理场 | 易负迁移：相关性与真实物理耦合不一致 |
| **GeoPT（lifted）** | 海量几何 + 合成动力学 | **粒子轨迹上的几何特征序列** | ✅（合成） | 任务条件"prompt"速度场 + 物理标签微调 | 关键在把任务条件编码成速度场 |

### 1.3 方法流程与数学形式

- 预训练阶段（无物理标签）：
  - 输入：几何 G + 采样点 x0 + 合成速度 v。
  - 轨迹更新：x_{t+1} = x_t + v * 1_outside_G(x_t)——点碰到几何边界就"粘住"。
  - 监督信号：h_G(x0:τ) = [h_G(x0), h_G(x1), ..., h_G(xτ)]，沿轨迹的几何特征序列。
  - 学习目标：Fθ(x0; G, v) 预测上述序列。
- 微调阶段（有物理标签）：
  - 把合成速度 v 换成任务条件 S 编码的速度场 V_S。
  - 学习目标：Fθ(x; G, V_S) → 真实物理场 u(x)。

数学形式〔HB〕：

```text
真实动力学的一种抽象:  dx_t/dt = v_S(x_t, t) · 1_outside_G(x_t),  x_0 = x
合成动力学（预训练用）: dx_t/dt = v · 1_outside_G(x_t),  v ~ Uniform(B)

预训练损失:  L_pre_lifted = E_{x,G,V} ‖ Fθ(x; G, V) − h_G(x0:τ) ‖²
下游损失:    L_physics   = E_{(x,G,S,u)} ‖ Fθ(x; G, S) − u(x) ‖²
```

- `1_outside_G(·)` 表示点是否在几何外部（撞边界即停/粘住）；`B` 为有界球，合成速度幅值有上限。
- 监督特征 h_G 论文默认 **vector distance**；消融显示比 SDF 更有效〔HB〕。

| 阶段 | 输入 | 学习目标 |
|---|---|---|
| 预训练 | (G, V) 合成 | 几何特征沿轨迹的演化 |
| 微调 | (G, V_S) 任务 | 真实物理场 |

## 2. 机制解读

- 几何提升：静态几何被合成动力学"提升"到动态空间，数据规模不再受真实物理标签限制。
- 为什么能提前获得物理直觉：轨迹演化自带空间耦合与边界作用（接触/粘住），模型在无标签数据上先学到"物体会怎么动"。
- 结果：极少真实物理标签下更稳更快地学习；预训练完成后再用真实标签微调。
- 理论视角〔HB〕：粒子追踪可解释为**相空间输运方程 + 粘性边界条件**，且具有质量守恒结构——随机速度下的学习，相当于让网络在多种几何/速度配置下内化一种保守结构，这就是可迁移物理先验的来源。
- 三个可复述直觉〔HB〕：
  - **耦合**：速度场把远处点经同一条传输路径"联系起来"，逼模型学到动力学相关性；
  - **边界**：粒子撞到几何边界即"粘住"，自监督信号天然含边界条件/几何约束；
  - **统一接口**：预训练与微调同用 (G, V)，微调只是把随机 V 换成 V_S（任务 prompt），**避免预训练空间与下游空间错配**。

## 3. 学术思想 vs 工程落地差异

- 论文强调：自监督信号设计、几何先验、少量标签微调的可扩展性。
- 落地要补：
  - 数据规模与几何质量（G 的精度决定预训练上限）。
  - Loss 设计与轨迹采样策略（边界"粘住"的数值稳定性）。
  - 评测口径：合成动力学学到的是"直觉"，最终收益要靠真实域回归验证。

### 3.1 预训练数据配方（论文实操）〔HB〕

- 几何库：ShapeNet（cars / airplanes / watercraft），1e4+ 几何。
- 采样点：每几何体 32,768 个体素空间点 + 4,096 个表面点，合计 36,864。
- 动力学：每几何体 100 组随机速度场；轨迹离散 3 个时刻（τ=2）。
- 几何特征：vector distance（见 1.3 消融结论）。

### 3.2 成本结构：合成监督为什么便宜〔HB〕

- 跟踪一个 geometry-dynamics 样本（36,864 点）约 **0.2 秒（80 核 CPU）**。
- 离线生成约 **1,346,300 个样本（约 5TB）**，80 核 CPU 约 **3 天**完成。
- 对照：工业 CFD 标签（论文引述 DrivAerML）单样本可达 **6.1×10^4 CPU-hours** 量级。
- 结论：合成监督与 solver 标签之间的成本差，就是"可扩展性"的来源——这也是"百万级预训练样本"在工程上可行的原因。

### 3.3 Backbone 与规模〔HB〕

- 方法对 backbone 近似无关；论文默认 Transolver，给出 8/16/32 层（约 3M/7M/15M 参数）。
- 小数据工业仿真下从头训练有扩模瓶颈（过拟合）；GeoPT 预训练起"正则化假设空间"的作用，让扩模收益更稳定。

## 4. 迁移与延伸判断

- Sim2Real 适用条件：几何域与真实域的结构差异可控时，迁移收益最大。
- 错配修正红线：预训练输入空间（几何表示、坐标系、速度场参数化）与真实任务不一致，微调会失效或倒退。
- 边界接触约束对具身场景尤其相关：接触/粘住正是操作任务的物理核心。
- 论文实测的三类风险点〔HB〕——与红线逐条对照：

| 风险点 | 论文观测 | 对应红线/落地判断 |
|---|---|---|
| 条件降维 | 把复杂仿真条件压成一个速度场 V_S 可能丢信息（材料、边界类型等） | 预训练输入空间不匹配红线：V 的参数化决定上限 |
| prompt 配置敏感 | 速度方向/幅值离谱会激活错误相关性导致掉点（论文做了方向偏移与速度扫描消融） | V_S 编码需扫描校准，不是任意可配 |
| 几何域外 | 预训练几何与下游几何差距过大时，收益变小甚至训练更不稳定 | 域错配红线：合成几何分布必须覆盖下游/采集域 |

- 关键消融结论〔HB〕：**几何多样性比动态多样性更关键**——几何多样性是主要瓶颈，合成数据配方应优先堆几何多样性。
- 跨域证据〔HB〕：除流体（汽车/飞机/船舶）与碰撞固体力学外，论文额外展示了 radiosity 任务的跨域泛化，支持"通用可迁移先验"的判断。
- 相关工作定位〔HB〕：
  - 物理 foundation model（PDE 预训练）：仍依赖昂贵物理标签；GeoPT 预训练阶段零物理标签，靠几何 + 合成动力学扩展数据。
  - 静态几何表征 + conditioning：几何只作辅助输入（3D encoder token），缺动力学；GeoPT 把动力学纳入预训练监督信号本身。
  - native-space 几何自监督：易负迁移——GeoPT 要解决的正是"几何-物理空间不一致"。

## 5. 迁移设想：应用到 L2 感知管线

- 结合第一章，切入点候选：
  - 手部重建（场景 A）：用合成手部几何 + 接触动力学做自监督预训练，再少量真实标注微调。
  - 相机位姿（场景 B）：合成场景轨迹提升自监督，缓解真实第一视角数据不足。
  - 深度估计（场景 C）：几何提升的思路可用于深度-法线联合自监督。
- 收益预期：降低真实标注依赖；前提是几何域与采集场景域对齐。
- 迁移风险：L2 模型是"感知"而非"动力学预测"，迁移时要重新定义 V 与监督信号的含义——这是待验证的核心假设。
- 用论文实测结论反哺的落地注意〔HB〕：
  - **数据配方**：按"几何多样性 > 动态多样性"的消融结论，场景 A/B/C 造合成数据时优先堆场景结构 / 手形 / 物体形状多样性，速度场与动力学配置其次；
  - **prompt 校准**：迁移中重新定义的 V 必须做方向/幅值扫描消融，确认不激活错误相关性（对应"prompt 配置敏感"风险）；
  - **域覆盖**：合成几何分布要覆盖真实采集域，控制"几何域外"风险（呼应第 4 节域错配红线）。
