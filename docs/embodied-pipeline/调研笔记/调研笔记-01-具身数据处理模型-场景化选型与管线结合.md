# 调研笔记 01：具身数据处理模型——场景化选型与管线结合

> 调研底稿：《具身数据管线工程笔记》第一章由本篇提炼而成。本篇记录调研过程与原始信息：管线上有哪些数据处理模型、各场景怎么选、选完怎么嵌入 L2 层跑通。
> 数据流细化（2026-10-01 补入）：L2 模块级细化数据流与完整依赖关系（各模块上游输入 / 内部链路 / 输出分发 / 关键工程信息）已提炼并入第 2 章各场景小节，L2 边界与环路红线并入第 3 章。

## 0. 调研背景与问题

- 具身数据管线（第一视角视频 → L1 预处理 → L2 感知重建 → L3 语义 → L4 清洗封装）里，L2 是模型密度最高、出错成本最高的一层。
- 要回答的问题：
  1. 每一类任务（手部、相机、深度、分割、位姿）业内主流模型是什么？
  2. 场景条件（遮挡、动态、零样本、首帧提示）不同时，选型怎么变？
  3. 多个模型同管线运行时，段间依赖和回注怎么组织？

## 1. 模型场景地图（总览）

| 场景（模块） | 任务 | 候选模型 | 选型要点 |
|---|---|---|---|
| 手部重建（②） | 检测 + MANO 参数化 | YOLO / WiLoR → MANO，升级 HaWoR | 遮挡鲁棒、尺度锚 scale_factor |
| 相机位姿（③·坐标系枢纽） | 场景相机轨迹 | MegaSaM / DROID-SLAM / GeoCalib | 先验来源（视差 / 深度）、有无内参分支 |
| 单目深度（④·尺度源） | 逐帧深度 | MoGe / Depth Anything V2 | 一个模型喂多个下游、双模型互检 |
| 分割跟踪（⑤） | 时序 mask | EgoHOS / Grounded-SAM / SAM2 / TAPIR | 首帧提示 → 传播 → 点轨迹 |
| 物体位姿（⑥） | 6DoF 跟踪 | FoundationPose | RGB-D 零样本，CAD / 少样本两模式 |

## 2. 逐场景调研

> 每场景统一模板：任务定义 → 候选与选型 → 上游输入（含回注）→ 内部链路 → 输出规格 → 关键工程信息与质检指标。

### 场景 A：手部检测与重建（模块②）

- 任务：检测手 → MANO 参数化（形状 β + 姿态 θ）→ 单只手每帧 54 维（相机系）。
- 候选与选型：YOLO / WiLoR 出检测；HaWoR 升级位（世界系一体化路线、遮挡下更稳，兼作全链路尺度锚 scale_factor，可给场景 E 提供初值）；遮挡鲁棒交给 Masked DROID-SLAM。
- 上游输入：
  - L1：RGB 规范化帧序列 + 时间戳；
  - 回注④：FoV 视场参数，用于手部 2D 投影约束；
  - 回注③：`camera_to_world[T,4,4]`，仅做后处理坐标变换，**不参与 MANO 拟合优化**。
- 内部链路（串行三步）：
  1. WiLoR / YOLO 手部检测 → 2D 框、手部 2D 关键点、手部朝向初值（朝向初值 WiLoR 独有，YOLO 仅出框）；
  2. MANO 参数拟合（2D 关键点 + 朝向初值 + 内参）→ 形状 β(10维)、姿态 θ(45维)、关节 3D 坐标、腕位(3维)、旋转 6D(6维)；
  3. Masked DROID-SLAM 时序平滑（用⑤手部 mask 做遮挡屏蔽）→ 平滑后的腕位 / 6D 旋转 / 45 维关节；只优化姿态时序连续性，**不修改形状参数 β**。
- 输出规格：`hand_joint_cam[T,45]`、`hand_wrist_cam[T,3]`、`hand_rot6d_cam[T,6]`（54 维 = 腕位 3 + 旋转 6D 6 + 关节 45）；世界系 = camera_to_world @ 相机系；附属输出：手部 mask 二值图时序 → ⑤（辅助分割）。
- 关键工程信息与质检：
  - MANO 拟合全程在相机系，不直接输出世界坐标，必须靠③外参后变换；
  - 回注的 camera_to_world 不能回灌进 MANO 优化回路，否则把 SLAM 漂移放大到手部参数；
  - 坏 case：手被物体大面积遮挡、关键点失效 → MANO 崩坏；
  - 质检指标：手部重建成功率、关键点可见占比。

### 场景 B：相机位姿估计（模块③·坐标系枢纽）

- 任务：估计 `camera_to_world[T,4,4]`（全链路最重要的坐标转换矩阵）。
- 候选与选型：MegaSaM（动态场景重建，CVPR 2025）优先；遮挡密集时 DROID-SLAM 兜底；GeoCalib 补无内参分支。
- 上游输入：
  - L1：RGB 帧序列 + 时间戳；
  - L1 元数据：AR 眼镜/头显原始内参；互联网 ego 视频带「无内参」标记；
  - 先验注入④：MoGe 深度图，作为稠密 SLAM 深度先验（不强制绑定深度尺度）；
  - 辅助输入⑤：手/物体 mask，动态区域屏蔽，降低动态物体对轨迹的干扰。
- 内部分支：
  - 分支 A（有标定内参）：MegaSaM / DROID-SLAM 直接求解 → camera_to_world + 场景稀疏/半稠密跟踪点；
  - 分支 B（无标定内参）：GeoCalib 前置预测焦距/主点/畸变（恢复虚拟内参）→ 再进 SLAM 求解。
- 输出与分发（3 处）：`camera_to_world[T,4,4]`、相机光心世界坐标、旋转四元数时序、稀疏点云 → 回注②（手部抬世界系）、送⑥（物体抬世界系）、供 L2 全局一致性校验。
- 关键工程信息与质检：
  - 深度先验仅作 SLAM 初始化与约束项，SLAM 仍会尺度漂移——这是整条管线尺度不一致的根源；
  - 动态物体（手运动、移动物体）会破坏 SLAM，优先用⑤mask 屏蔽；
  - 互联网视频完全依赖 GeoCalib 预测内参，预测误差持续传导给所有下游；
  - 质检指标：SLAM 跟踪丢失率、轨迹平滑度、重投影误差。

### 场景 C：单目深度估计（模块④·尺度源）

- 任务：逐帧深度图 + 点云 + 法线图 + FoV；无回注输入，是 L2 的前向源头模块。
- 候选与选型（工业量产双模型互检）：MoGe（metric 真实尺度，主尺度基准）；Depth Anything V2（相对深度/视差，高速、泛化强，做互检）。
- 内部双模型逻辑：MoGe → metric 深度 / 点云 / 法线 / FoV；DAv2 → 视差图（无绝对尺度）。
- 输出分发（5 路）：
  1. MoGe 深度 → ③深度先验注入 SLAM；
  2. MoGe FoV → 回注②手部 2D 投影约束；
  3. MoGe 深度 → ⑥FoundationPose 的 RGB-D 之 D 通道；
  4. DAv2 视差 ↔ MoGe 互检，检测深度异常帧；
  5. 逐帧法线图、点云 → L2 产物输出，供 L3。
- 关键工程信息与质检：
  - MoGe 宣称 metric 尺度，但互联网视频、弱纹理、遮挡下仍会尺度漂移，不能无条件信任绝对尺度；
  - DAv2 是相对深度，不能单独作③的深度先验产出绝对尺度轨迹，只能做辅助校验；
  - 全链路尺度源头：深度漂移会传导给相机轨迹、手部、物体 6DoF；
  - 质检指标：深度置信度占比、MoGe 与 DAv2 一致性误差、无效深度像素占比。

### 场景 D：分割与实例跟踪（模块⑤）

- 任务：手/物 mask 时序轨 + 接触边界标注。
- 候选与选型：首帧提示降人工成本、时序传播保一致性、点轨迹补接触细节。
- 上游输入：L1 RGB 帧序列 + 时间戳；辅助输入②手部 mask（提升手部分割精度）。
- 内部链路：
  1. 首帧实例分割冷启动二选一——路径 A（ego 视角优先）EgoHOS：首帧 RGB → 手/交互物体 mask；路径 B（开域未知物体）Grounded-SAM：首帧 RGB + 文本 prompt → mask；
  2. SAM2 时序传播：首帧 mask + 全帧序列 → 跨帧时序 mask；
  3. TAPIR 稠密点轨迹：时序 mask + RGB 视频 → 手-物接触边界 2D 点轨迹。
- 输出分发（4 路）：手部 mask → ②遮挡屏蔽；手/物体 mask → ③动态区域屏蔽；mask + 接触点 → ⑥ROI 裁剪；原始输出 → L3（接触边界是动作分割、VLM 指令生成的物理依据）。
- 关键工程信息与质检：
  - 首帧 mask 失效则 SAM2 全时序跟踪崩坏，需设首帧质检门；
  - TAPIR 输出 2D 点，结合④深度 + ③外参才能得到 3D 接触点；
  - 质检指标：mask 时序 IoU 衰减率、接触点有效性。

### 场景 E：物体 6DoF 位姿（模块⑥）

- 任务：物体位姿轨（相机系 → 经③抬升到世界系）。
- 候选与选型：FoundationPose（RGB-D 零样本跟踪）；初值可接场景 A 的 HaWoR 尺度锚。
- 上游输入：L1 RGB 帧；④MoGe 深度图（组成 RGB-D）；⑤物体 mask 时序（ROI 裁剪）；③`camera_to_world`（仅后处理坐标抬升，**不参与 6DoF 优化求解**）。
- 两种工作模式：CAD 模型模式（物体 CAD 模板，零样本 6DoF 跟踪）；少样本免 CAD 模式（test-time 优化构建物体模板）。
- 输出规格：`obj_pose_cam[T,4,4]`；世界系 = camera_to_world @ obj_pose_cam。
- 关键工程信息与质检：
  - 优化求解全程在相机系，物体世界坐标完全依赖③矩阵；
  - 深度来自 MoGe 单目估计，深度误差直接放大物体位姿误差；
  - 物体遮挡、出帧会造成跟踪跳变、丢失；
  - 质检指标：物体跟踪成功率、位姿时序跳变幅度。

## 3. 结合实际管线：L2 数据流、依赖关系与环路红线

### 3.1 L2 边界：上层输入与整体输出

- 位置：L1 规范化帧流之后、L3 语义之前，五模块并行/串行组合。
- 上层输入（L1 输出）：规范化帧流——统一帧率/分辨率、去畸变、JPEG 图像序列；元数据：原始内参（AR/头显）或「无内参」标记（互联网 ego 视频）、时间戳序列。
- L2 整体输出（**世界系结构化轨迹产物**，全部字段带时间戳对齐）：手部 MANO 时序、相机外参轨迹、场景点云/法线、实例 Mask 时序、手-物接触点轨迹、物体 6DoF 时序 → 送 L3 语义层。

### 3.2 核心约束（坐标系与尺度）

- ③相机位姿模块是**坐标系枢纽**，④深度模块是**尺度源头**。
- 所有模块输出默认**相机系**，必须经 camera_to_world 矩阵变换才得到世界系。
- 模块间前向输入 + 回注反馈环路并存：环路必须增加收敛校验，**禁止无限制迭代**。

### 3.3 模块间依赖与回注关系（完整清单）

| 源 → 目标 | 传递物 | 用途 |
|---|---|---|
| ④ → ③ | MoGe 深度图 | SLAM 深度先验（不绑定尺度） |
| ④ → ② | FoV | 手部 2D 投影约束 |
| ④ → ⑥ | MoGe 深度图 | RGB-D 的 D 通道 |
| ② → ⑤ | 手部 mask | 辅助手部分割 |
| ⑤ → ② | 手部 mask | Masked DROID-SLAM 遮挡屏蔽 |
| ⑤ → ③ | 手/物体 mask | SLAM 动态区域屏蔽 |
| ⑤ → ⑥ | 物体 mask + 接触点 | ROI 裁剪 |
| ③ → ② | camera_to_world | 手部抬世界系（仅后处理） |
| ③ → ⑥ | camera_to_world | 物体抬世界系（仅后处理） |
| ⑤ → L3 | mask + 接触边界 | 动作分割 / VLM 指令的物理依据 |

- 中间产物清单：深度图 / mask 轨 / camera_to_world / 手部参数 / scale_factor / 物体位姿轨。

### 3.4 关键环路风险（工程红线）

1. **禁止把③输出的 camera_to_world 回灌进②MANO 拟合、③SLAM 优化、⑥6DoF 优化回路**——只能用于后处理坐标变换，否则误差循环放大发散。
2. 尺度链条：MoGe 深度 → SLAM 相机轨迹 → 手部/物体抬世界；每一步都引入漂移，**不能假设三者天然对齐**，L2 出口必须统一做几何一致性校验。
3. 互联网视频无硬件标定内参，完全依赖 GeoCalib 预测内参，误差沿全链路传递。

### 3.5 出口质检门与下游衔接

- 出口质检门：世界系一致性校验（手、场景、物体四层标注对齐），违规率 / 重建成功率 / 分层准确率。
- 下游衔接：L3 动作分割（腕部速度曲线 → 原子动作 → VLM 指令）、L4 清洗封装（LeRobotDataset v3.0）。

## 4. 效果衡量（配套）

- S1 自洽：管线工程指标（重建成功率、分层准确率、违规率）；各模块 S1 级质检指标已并入第 2 章各场景「关键工程信息与质检」。
- S2 精度：三套 GT（仿真合成 / 伪 GT / 真实 Hold-out 集）。
- S3 下游收益：训练回归（通吃率、人工介入率）。
- 版本回归：Golden Set 防倒退；评测绑数据集版本号。

## 5. 选型红线与风险

- 域错配：模型训练数据域 ≠ 采集场景域，先做域校验。
- 预训练输入空间不匹配：分辨率 / 内参 / 帧率与模型训练口径不一致。
- 尺度不一致：单目深度与手部尺度锚必须统一到世界系（详见 3.4 尺度链条）。
- 遮挡失效：手/物互遮挡时 mask 与位姿退化，需检出门兜底。

## 6. 待确认项

- HaWoR / MoGe / MegaSaM 的实测精度与显存占用（待跑 benchmark）。
- FoundationPose 少样本模式的最低样本数与鲁棒边界。
- 各模型推理耗时在单卡/多卡上的占比（供 L2 感知池资源配置）。
