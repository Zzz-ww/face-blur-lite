## 总评

**拓扑抄的是 Netflix，算子停在 2015，验收是自证清白式的。** 像一台手工打磨的变速箱
装在老发动机上——控制面每个齿都比教科书细，数据面每帧却付两次全帧 memcpy，
"糊没糊干净"的最终裁判还是生产端那把检测器。

| 镜头 | 一句话判词 |
|---|---|
| 数据面 | 拓扑抄对了 Netflix，算子停在 2015——"零拷贝"只兑现了 frombuffer 那一行；天花板就是这台笔记本的 1080p |
| 模型层 | 算法内核是 2016 年水平的（YuNet 框检测+恒速外推+高斯糊矩形），验证方法论却是业界产线都罕见的；最大的窟窿不是模型小，是 qc 拿同一把 YuNet 量自己的盲区还自称"独立检测器" |
| 控制面 | 原子 Join、终态不可逆、双语言契约同测是真能打的两手；但 claim 抢下的 lease 在 complete 时不验持有者牌面、断点零续跑——变速箱锃亮，防抱死没装 |
| 质量面 | 旗舰真实视频上最优配置仍 308/2121、全配置 qc_failed，闸门对唯一真实样本 100% 红还照常出货——证明的是"我很懂哪里漏"，不是"没漏" |

## 最狠的几刀

1. **验收体系的地基是空的**（冷读新发现，已核实代码坐实）。两层：
   qc"独立检测器"实为同一把 YuNet——其盲区（16–32px 小脸、域移）在源域和输出域
   完全共享，14.5% 残余是**下界**不是答案；叠加**相位锁相复发**——
   [ffmpeg_io.py](../src/faceblur_lite/ffmpeg_io.py) `offset = stride//2` 使 30fps@1fps
   抽样恒取 i≡15 (mod 30)、15 mod 3 = 0 → 例行 qc **只抽中检测帧**，2/3 预测帧零覆盖
   （det_every=2 时反向锁死）。BUG-010 的 postmortem 写了两条方法论，第二条恰好描述了
   自己的默认参数——修复只改了相位落点，锁相本身原样存活。**BUG-016 候选**。
   全密度验收（sample_fps=None）能兜住但 CLI 不可达。
2. **"qc_failed 但照常出货"**。闸门无判别力：对唯一真实样本所有配置全红（最优 308/2121），
   红灯常亮等于没有灯——无隔离区、无分级（致命/边缘）、n=1 之外无第二个样本校准阈值。
3. **数据面免费加速一个没碰**。VideoToolbox 硬解、batch 推理、进程间搬运消除——
   白捡的 2–5× 全留在桌上。不是架构问题，是纯粹没做。
4. **控制面经典竞态没设防**。lease 过期回收重派后，僵尸 worker 的迟到 complete 仍能命中
   `WHERE status='running'`（现任的 running），把别人的半成品标成 done。SQS 用 receipt
   handle 就是防这个。
5. **chunk 边界 = BUG-011 复发位点**。每 chunk 头部跟踪器从零冷启动（~9 帧 vel 爬坡），
   五层异常矩阵未收录此行——批量模式每 30s 制造一个已知弱区。

## 反超点（做得比业界认真的）

- **契约先行双控制面**——SQLite/Go 两实现过同一份 12 场景契约测试，全仓库最值钱的一行抽象
- **阈值分域**（det_conf 0.3 源域 / pass_conf 0.5 输出域）——"置信度不跨编码域守恒"钉成硬约束
- **BUG-010 取证链**——像素级 MSE 定谳相位偏移，SRE 范本级 postmortem（讽刺：修复自身又锁相，见刀 1）
- **并集糊**——脱敏门禁从跟踪器出生策略中解耦，职责分离干净
- **原子 Join + 全局钉死编码参数** → concat 秒级合并，scatter-gather 的 fan-in 做对了

## 一句话定位（面试语境）

卖点不是"能脱敏视频"，而是"一个人把数据平台的全套错误模型（幂等、租约、终态、契约、
相位、取证）在小尺度上全踩过一遍并有文档"。算法层就是 2016 年的，不包装；
工程方法论层是真金，重点讲。
