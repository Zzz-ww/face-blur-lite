# BUG-015：大脸比例核成本爆炸 + single 静默假死（降采样快路径）

- **日期**：2026-09-25
- **发现场景**：用户跑 `blur.sh run inputs/celebv/`（CelebV 特写样本），
  20 秒的片子在 single 模式下"卡死"——**901s 仍未跑完**（被中断时止于
  429/500 帧，~2.1s/帧；外推全片 ≈17.5min），期间零输出、内核 1356% CPU 满载。

## 现象与取证

- 输入画像：20.01s / 1148×1148 / 25fps / 500 帧，单人脸 **440–530px 特写大脸**
  （偶发第二脸），对比 real_video 是 16–50px 小脸——大脸区间首次进入实测。
- 进程活着（输出文件持续增长、3s +262KB），排除死锁；是病态慢。

## 根因

两个独立问题叠加：

1. **比例模糊核无上限**（`blur.py`）：`k = 0.75×crop短边`。小脸 k≈37，
   大脸 crop≈600×690 → **k≈450**（短边 598–600 → k 449–451），高斯成本
   O(k×像素)——单次糊 ~370M 运算，
   500 帧 + 检测帧并集双糊 ≈ 250G 运算。这是"σ 与人脸尺度相当"设计的
   代价面，逻辑正确但成本模型随内容区间爆炸（约 100 倍于小脸场景）。
2. **single 模式静默**（`blur.sh`）：内核 stdout（JSON 总结）/stderr 全部
   重定向进临时文件，跑多久都没有一行输出——慢 + 静默 = 假死观感。

## 修复

1. **大核快路径**（`blur.py`）：`k > 201`（crop 短边 >269px）时改为
   **降采样（INTER_AREA 到短边 ≈268px）→ 按同比例糊小图（k 仍 75%）→
   放回（INTER_LINEAR）**。σ 视觉等效：比例不变，冲激响应实测
   σ_eff/σ_direct∈[0.995,1.01]（偏差有界，远小于验收带），成本 O(像素)。
   小/中脸路径逐位不变（real_video、demo 场景零行为变化）。
2. **心跳输出**（`blur.sh`）：single 模式后台子 shell 每 15s 报
   `⏳ 处理中：xx 已写出 N MB`；`sleep 放后台再 wait` 使 TERM 即刻生效
   （前台 sleep 15 会把 kill 推迟到 sleep 结束，捕获式调用白吃 15s 死尾）；
   存活检查感知僵尸父进程（`kill -0` 对未收殓僵尸恒真，STAT 含 Z 视为
   死亡，防调用方不收殓时心跳永转持住管道）；`trap TERM` 自愿退出
   （被 kill 时 bash 不打 "Terminated" 噪声）。

## 实测（celebv 样本，端到端）

| 路径 | 内核耗时 | 产物 | qc |
|---|---|---|---|
| 直接大核（旧） | 901s **被中断**（~2.1s/帧） | 429/500 帧（视频流 17.16s） | 17 帧 0 违规（截断成品，覆盖 86%） |
| 降采样快路径 | **116s** | 500 帧完整（视频流 20.000s） | 20 帧 0 违规 |

提速 **≈9×**（外推口径：慢路径全片 ≈1050s；即便按 901s 保守下限也 ≥7.9×）。

> **基线口径勘误（对抗核查抓出）**：初稿误记"913s 跑完、时长逐帧一致
> （20.011s）"。实际慢路径运行被中断于 429/500 帧，容器 20.011s 是音轨
> 字节直拷撑起的虚标——视频流只有 17.16s。qc 抽 17 vs 20 帧正是截断的
> 确定性抽样（stride=25：500 帧→20 样本、429 帧→17），不是波动。

`test_small_and_boundary_boxes_stay_direct_path`（≤269 短边逐位一致）、

`test_fast_path_multi_box_margin_combo`（多框+margin 放回尺寸）、
`test_fast_path_edge_spread_width_matches_direct`（阶跃边展宽双侧锚定 σ，

## 教训

- **比例参数要带成本上限**：核随内容线性增长的设计，在"特写大脸"这类
  长尾区间成本平方级爆炸——等效果可由"降采样+同比例小核"以 O(像素) 达成。
- 性能特征随内容区间变化：参数在小脸内容上调优（BUG-005 的 0.75），
  不代表大脸区间也可用——每个内容档位要有实测。
- 长任务静默 = 假死：CLI 包装层对 >10s 的子进程必须有进度出口。
- **成品完整性看视频流，别看容器时长**：音轨字节直拷会把 format
  duration 撑满、掩盖视频截断（本例 17.16s 视频 + 20.01s 音轨）；A/B
  基线必须完整跑完再下结论——截断基线连"提速倍数"都是错的。
