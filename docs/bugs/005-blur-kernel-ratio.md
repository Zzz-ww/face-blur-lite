# BUG-005 0.15 模糊核只抹高频，低频身份结构存活

- **发现**：2026-09-24，Task 5 修复 BUG-004 之后——覆盖问题解决，std 仍 0.891
- **现象**：取样窗口已完全落入模糊足迹，方差下降仍不达标
- **根因**：Gaussian 核大小决定**抹掉哪个频段**。0.15×min(边) 的小核只平滑高频纹理；脸部特写自带强低频对比（深色头发 vs 亮色皮肤的大块结构），身份信息恰恰在低频——小核对隐私脱敏语义上是无效模糊
- **修复**：`blur.py` 核比例 0.15→0.75。走计划 Step 4 明文协议（"确认模糊强度→调核大小，不许放宽断言"）+ 实测扫描选值：0.15→0.884 / 0.30→0.813(仍败) / 0.50→0.749(余量薄) / **0.75→0.693(取，13% 余量)** / 1.0→0.651。断言不动；test_blur.py 不钉核大小，无回归
- **教训**："宁可多糊"的隐私语义要求摧毁的是低频结构而非高频纹理——核大小选值应从"还能不能认出是谁"出发，而不是"看起来糊了"。大核是正确方向，不是为过测试的妥协
