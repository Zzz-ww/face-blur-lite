# BUG-004 YuNet 只检 lena 内脸，std 断言数学不可满足

- **发现**：2026-09-24，Task 5（kernel）实施轮——verbatim 实现过不了计划自带的 std 断言
- **现象**：`crop_out.std() < crop_in.std() * 0.8` 失败（实测 0.877 vs 要求 <0.80），按计划 Step 4 协议调大模糊核**完全无效**
- **根因**：测试假设"贴图≈脸"，但整张 lena（帽/肩/背景）缩放成 120px 贴图后，YuNet 只检出**内脸** ~36×48px；检测框+margin 足迹只盖测试 100×100 取样窗口的 **31%**。模糊只能改框内像素——69% 像素永不可触碰，组合 std 的理论下限 √0.69≈0.83（实测 0.877）**与核大小无关地**大于 0.80
- **修复**：`testmedia.load_face` 把 lena 裁成脸部特写（`img[170:400, 185:385]`）→ 贴图≈检测框。实测：特写 sprite 上 conf=0.874、框盖贴图 73%W/83%H、足迹完全包含取样窗口。断言与测试保持原文
- **教训**："覆盖率"型断言先算**可达集合**——取样窗口必须落在模糊足迹内才谈得上强度；fixture 的内容假设（贴图≈脸）要用检测器实测验证，不能靠肉眼直觉。附带收益：特写让所有下游人脸相关断言（遮挡 E2E、qc）信号更强
